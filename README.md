# OpenGL Renderer

A personal project I'm building to learn real-time 3D graphics using C++ and OpenGL.

## Current Features

- Free-moving camera with mouse and keyboard controls
- Textured 3D meshes with basic lighting
- GLSL shaders for vertex and fragment processing
- Model, view, and projection transformations
- Separate classes for meshes, shaders, textures, cameras, and scene management

## Built With

C++ · OpenGL · GLSL · GLFW · GLAD · GLM · CMake

## Building

The project uses CMake and vcpkg to manage dependencies. It requires GLFW, GLAD, GLM, and stb_image.

## Status

Work in progress. Currently focused on understanding the rendering pipeline and building a foundation for more advanced graphics techniques.
